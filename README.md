# Saha Specialists Website

**Responsive front-end website for Saha Specialists, an aluminium business based in Kelantan, Malaysia, specializing in doors, windows, kitchen cabinets, and custom solutions.**

---

## About the Business
Saha Specialists focuses on aluminium products and services, including:

- Aluminium doors and windows
- Kitchen cabinets
- Installation and maintenance
- New builds or custom-made solutions based on existing or bespoke designs

The company is based in **Kelantan, Malaysia**, and aims to expand its services nationwide.

---

## Project Overview
This repository contains the source code for the website, designed to balance the **bold, gradient-heavy logo** with a **clean and modern layout**. The website is responsive, user-friendly, and optimized for desktop and mobile viewing.

**Design Goals:**

- Highlight the brand’s logo without overwhelming the user
- Provide a professional, readable interface
- Emphasize white space to create contrast
- Use color strategically for call-to-actions

---
